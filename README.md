# مشوار وحكي من القلب ❤️

نسخة محسّنة من الموقع الرومانسي، تشمل:
- انتقالات وحركات لطيفة وعناصر قلوب متحركة.
- أزرار خيارات مع رموز تعبيرية.
- زر «لا» يهرب عند محاولة الضغط عليه.
- بطاقة دعوة نهائية بتصميم خاص مع خيار إنشاء البطاقة وحفظها كصورة PNG أو مشاركتها.

## النشر
ارفع `index.html` إلى مستودع GitHub Pages بدل الملف القديم. لا حاجة لملفات CSS أو JavaScript منفصلة؛ كل شيء مضمّن في `index.html`.
