مشوار وحكي من القلب ❤️

الملف الرئيسي للموقع: index.html
الموقع مبني بـ HTML وCSS وJavaScript ولا يحتاج تثبيت أي مكتبات.

لنشره عبر GitHub وRender:
1. نزّل ملف ZIP وفك ضغطه.
2. افتح GitHub وأنشئ مستودعًا جديدًا باسم date-night-romantic (أو استخدم المستودع الموجود).
3. ارفع index.html وREADME.txt إلى جذر المستودع، وليس داخل مجلد فرعي.
4. في Render اختر New + ثم Static Site واربط مستودع GitHub.
5. Build Command اتركه فارغًا، وPublish Directory اكتب . (نقطة فقط).
6. اضغط Deploy Static Site وانتظر اكتمال النشر. Render سيعطيك رابطًا عامًا للموقع.
